# Open this project in Codex

1. Create a new **private** GitHub repository named `lafix-2` under your account.
2. Extract this archive to a local folder; open a terminal in its root.
3. Run:

```bash
git init
git add .
git commit -m "Initial LaFix 2.0 Codex handoff"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/lafix-2.git
git push -u origin main
```

4. Open Codex, connect your GitHub account/repository and choose `lafix-2`. (Or open the extracted directory in a Codex-compatible editor.)
5. Paste the task instructions from `docs/CODEX_START_PROMPT.md` to start implementation.

Never commit live `.env` values or production user data. GitHub repository creation and Codex linking require your account authorization.
